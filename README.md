# AR METARION: Aplikasi Pembelajaran Tata Surya dengan Augmented Reality

AR METARION adalah aplikasi pembelajaran yang menggunakan teknologi **Augmented Reality (AR)** untuk membantu siswa memahami konsep-konsep dalam ilmu pengetahuan alam (IPA), khususnya tentang **tata surya**. Dengan menggunakan aplikasi ini, siswa dapat berinteraksi dengan model 3D planet-planet di tata surya untuk pengalaman belajar yang lebih imersif.

## Fitur Utama
- Menampilkan model 3D planet dalam tata surya
- Interaksi dengan objek AR: rotasi, zoom, dan informasi planet
- Tampilan yang mudah digunakan untuk siswa SD

## Teknologi yang Digunakan
- Unity 3D
- Vuforia untuk pelacakan AR
- C# untuk pengembangan skrip
